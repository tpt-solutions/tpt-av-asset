# tpt-av-asset

**A pure-Rust, background media asset management engine. Proxy generation, waveform caching, thumbnail indexing, and filesystem monitoring. The performance backbone of the TPT AV stack.**

**License:** MIT  
**Status:** Early-stage / Pre-1.0  
**Ecosystem:** [TPT Solutions Open Source](https://opensource.tptsolutions.co.nz/)

---

## 1. Vision & Philosophy

`tpt-av-asset` is the **media asset management layer** of the TPT AV Stack. It provides the background infrastructure that makes professional media applications feel instantaneous — even when working with massive 4K/8K video files or multi-hour podcast recordings.

The problem with most open-source media tools is that they either:
1. Block the UI while generating waveforms or proxies (feels "laggy" and amateurish)
2. Rely on proprietary asset management systems (Final Cut Pro, Premiere Pro)
3. Have no asset management at all (Audacity, basic editors)

`tpt-av-asset` solves this by providing:
1. **Background proxy generation** — lightweight versions of heavy media files for smooth playback
2. **Waveform peak caching** — pre-computed min/max peaks for instant waveform rendering
3. **Video thumbnail caching** — pre-computed thumbnails for timeline scrubbing
4. **Media database** — fast, concurrent indexing of all imported assets
5. **Filesystem monitoring** — automatic detection of file changes, moves, and deletions
6. **Background processing pipelines** — multi-threaded, prioritized job queues for all asset processing

### Core Tenets

1. **Background-First Architecture:** All heavy processing (proxy generation, waveform caching, thumbnail extraction) happens on background thread pools. The UI thread never blocks.
2. **Incremental & Resumable:** All processing jobs can be paused, resumed, and resumed after crashes. Partial progress is never lost.
3. **Cache-Invalidation Aware:** When source files change, caches are automatically invalidated and regenerated.
4. **Pure Rust, Zero External Dependencies:** Uses `redb` (MIT) for the embedded database. No SQLite, no C/C++ bindings.
5. **Real-Time Safe Reads:** Reading from caches (waveform peaks, thumbnails) is allocation-free and lock-free, safe for the audio/render thread.
6. **Pure MIT Licensing:** No GPL/LGPL/MPL dependencies. Enforced via `cargo-deny` in CI.
7. **Composable Architecture:** Each sub-crate is independently useful. A developer can use just the cache, just the proxy generator, or just the database.

## 2. Ecosystem Integration

`tpt-av-asset` sits in the **Performance Layer** of the TPT AV Stack, working behind the scenes to accelerate both `tpt-audio` and `tpt-visual`.

| Crate | Role | Relationship to `tpt-av-asset` |
| :--- | :--- | :--- |
| **`tpt-kinetix`** | Media containers, video codecs | Source of video frames for thumbnail generation. |
| **`tpt-cadence`** | Audio codecs | Source of PCM data for waveform peak generation. |
| **`tpt-audio`** | Audio processing | Reads waveform peaks from `tpt-av-asset` for UI rendering. |
| **`tpt-visual`** | Video processing | Reads video thumbnails from `tpt-av-asset` for timeline scrubbing. |
| **`tpt-av-asset`** | **Asset management (this repo)** | Background proxy generation, caching, indexing, and file watching. |

### Data Flow
User imports "4K_interview.mp4" (2 hours, 50GB)
↓
tpt-av-asset-watcher detects new file
↓
tpt-av-asset-db indexes file metadata (duration, resolution, codecs)
↓
tpt-av-asset-pipeline schedules background jobs:
Job 1: Generate proxy (1080p, low bitrate)
Job 2: Extract video thumbnails (every 1 second)
Job 3: Extract audio track
Job 4: Generate waveform peaks for audio track
↓
Background thread pool processes jobs (prioritized, resumable)
↓
tpt-av-asset-cache stores results in embedded database
↓
tpt-audio / tpt-visual read from cache (real-time safe, instant)

4. Core API Design
4.1. Asset Identification (tpt-av-asset-utils)

/// A unique, content-addressed asset identifier.
///
/// Computed from the file path + modification time + size.
/// This ensures that if a file is modified, it gets a new ID,
/// and old caches are automatically invalidated.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub struct AssetId {
    /// Hash of the file path.
    path_hash: u64,
    /// Modification time (Unix timestamp in milliseconds).
    mtime_ms: u64,
    /// File size in bytes.
    size: u64,
}

impl AssetId {
    /// Computes an asset ID from a file path.
    pub fn from_path(path: &Path) -> Result<Self, AssetError> {
        let metadata = path.metadata()?;
        let mtime = metadata.modified()?;
        let mtime_ms = mtime.duration_since(UNIX_EPOCH)?.as_millis() as u64;
        
        Ok(Self {
            path_hash: hash_path(path),
            mtime_ms,
            size: metadata.len(),
        })
    }
}

/// Media metadata extracted from a file.
#[derive(Debug, Clone)]
pub struct MediaInfo {
    /// Asset identifier.
    pub id: AssetId,
    /// File path.
    pub path: PathBuf,
    /// File name.
    pub name: String,
    /// File size in bytes.
    pub size: u64,
    /// Media type (audio, video, image).
    pub media_type: MediaType,
    /// Duration in seconds (if applicable).
    pub duration_secs: Option<f64>,
    /// Video-specific info.
    pub video: Option<VideoInfo>,
    /// Audio-specific info.
    pub audio: Option<AudioInfo>,
}

/// Video-specific metadata.
#[derive(Debug, Clone)]
pub struct VideoInfo {
    /// Width in pixels.
    pub width: u32,
    /// Height in pixels.
    pub height: u32,
    /// Frame rate (e.g., 24.0, 29.97, 30.0, 60.0).
    pub frame_rate: f64,
    /// Codec name (e.g., "h264", "av1", "prores").
    pub codec: String,
    /// Pixel format (e.g., "yuv420p", "rgb24").
    pub pixel_format: String,
    /// Bit rate in bits per second.
    pub bit_rate: Option<u64>,
}

/// Audio-specific metadata.
#[derive(Debug, Clone)]
pub struct AudioInfo {
    /// Sample rate in Hz.
    pub sample_rate: u32,
    /// Number of channels.
    pub channels: u16,
    /// Bit depth.
    pub bit_depth: u16,
    /// Codec name (e.g., "pcm", "aac", "opus").
    pub codec: String,
    /// Bit rate in bits per second.
    pub bit_rate: Option<u64>,
}

4.3. Waveform Cache (tpt-av-asset-cache)

/// Waveform peak cache for audio assets.
///
/// Stores min/max peak values for fixed-size chunks of audio.
/// This allows the UI to render waveforms at any zoom level
/// without re-reading the source audio file.
pub struct WaveformCache {
    /// Chunk size in samples (e.g., 1024, 4096).
    chunk_size: usize,
    /// Sample rate of the cached peaks.
    sample_rate: u32,
    /// Cached peaks (stored on disk).
    storage: CacheStorage,
}

/// A chunk of waveform peaks.
#[derive(Debug, Clone)]
pub struct WaveformChunk {
    /// Chunk index.
    pub index: usize,
    /// Minimum sample value in the chunk (0.0 to 1.0).
    pub min: f32,
    /// Maximum sample value in the chunk (0.0 to 1.0).
    pub max: f32,
    /// RMS (root mean square) value for loudness visualization.
    pub rms: f32,
}

impl WaveformCache {
    /// Creates or opens a waveform cache for an asset.
    pub fn open(asset_id: AssetId, storage: &CacheStorage) -> Result<Self, AssetError>;

    /// Writes a chunk of peaks to the cache.
    pub fn write_chunk(&mut self, chunk: &WaveformChunk) -> Result<(), AssetError>;

    /// Reads a chunk of peaks from the cache.
    ///
    /// # Real-Time Safety
    ///
    /// This method is allocation-free and lock-free.
    /// Safe to call from the audio thread.
    pub fn read_chunk(&self, index: usize) -> Result<Option<WaveformChunk>, AssetError>;

    /// Reads a range of chunks (for rendering a visible portion of the waveform).
    pub fn read_range(
        &self,
        start_index: usize,
        end_index: usize,
    ) -> Result<Vec<WaveformChunk>, AssetError>;

    /// Returns the total number of chunks in the cache.
    pub fn chunk_count(&self) -> usize;
}

4.7. Background Processing Pipeline (tpt-av-asset-pipeline)

/// A background processing job.
pub trait Job: Send + Sync {
    /// Returns the job ID.
    fn id(&self) -> JobId;

    /// Returns the job priority.
    fn priority(&self) -> Priority;

    /// Executes the job.
    fn execute(&mut self, progress: &ProgressReporter) -> Result<(), AssetError>;

    /// Returns the asset ID this job is for.
    fn asset_id(&self) -> AssetId;
}

/// Job priority levels.
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
pub enum Priority {
    /// Critical (UI-blocking, highest priority).
    Critical,
    /// High (user-initiated, high priority).
    High,
    /// Normal (background processing).
    Normal,
    /// Low (deferred processing).
    Low,
}

/// The background processing pipeline.
pub struct ProcessingPipeline {
    /// Job queue.
    queue: JobQueue,
    /// Worker thread pool.
    workers: WorkerPool,
    /// Progress tracker.
    progress: ProgressTracker,
}

impl ProcessingPipeline {
    /// Creates a new processing pipeline.
    pub fn new(num_workers: usize) -> Result<Self, AssetError>;

    /// Submits a job to the pipeline.
    pub fn submit(&self, job: Box<dyn Job>) -> Result<JobId, AssetError>;

    /// Cancels a job.
    pub fn cancel(&self, job_id: JobId) -> Result<(), AssetError>;

    /// Returns the progress of a job.
    pub fn get_progress(&self, job_id: JobId) -> Result<Option<JobProgress>, AssetError>;

    /// Waits for a job to complete.
    pub fn wait_for(&self, job_id: JobId) -> Result<(), AssetError>;

    /// Starts the pipeline (spawns worker threads).
    pub fn start(&mut self) -> Result<(), AssetError>;

    /// Stops the pipeline (gracefully shuts down workers).
    pub fn stop(&mut self) -> Result<(), AssetError>;
}

5. Performance Architecture
5.1. Multi-Level Caching

┌─────────────────────────────────────────────────────────┐
│  Level 1: In-Memory Cache (LRU, hot data)               │
│  - Recently accessed waveform chunks                    │
│  - Recently accessed thumbnails                         │
│  - Fast, allocation-free reads                          │
└─────────────────────────────────────────────────────────┘
                         ↓ (cache miss)
┌─────────────────────────────────────────────────────────┐
│  Level 2: On-Disk Cache (file-based)                    │
│  - All waveform peaks                                   │
│  - All video thumbnails                                 │
│  - Proxy files                                          │
│  - Persistent across restarts                           │
└─────────────────────────────────────────────────────────┘
                         ↓ (cache miss)
┌─────────────────────────────────────────────────────────┐
│  Level 3: Source File (slow, decode on-demand)          │
│  - Original media files                                 │
│  - Only accessed when cache is invalidated              │
└─────────────────────────────────────────────────────────┘

5.2. Thread Architecture

Main/UI Thread (Can Allocate, Can Block)
│
│  Import media files
│  Query database
│  Read from cache (real-time safe)
│  Update UI
│
Background Worker Threads (Can Allocate, Can Block)
│
│  Generate waveform peaks
│  Generate video thumbnails
│  Generate proxy files
│  Process job queue
│
File Watcher Thread (Async, Can Block)
│
│  Monitor filesystem changes
│  Detect file modifications
│  Trigger cache invalidation
│
Audio/Render Thread (Real-Time Safe, Zero Allocation)
│
│  Read waveform peaks from cache
│  Read thumbnails from cache
│  Never write to cache
│  Never block

7. Dependency & Licensing Rules
Allowed Dependencies (Permissive Only)
tpt-av-asset-utils (internal)
tpt-av-asset-db (internal)
tpt-av-asset-cache (internal)
tpt-av-asset-proxy (internal)
tpt-av-asset-watcher (internal)
tpt-av-asset-pipeline (internal)
tpt-kinetix (MIT) — for reading video files
tpt-cadence (MIT) — for reading audio files
redb (MIT/Apache) — embedded database
notify (MIT/Apache/CC0) — filesystem watching (wrapped by tpt-av-asset-watcher)
image (MIT) — thumbnail resizing and encoding
serde (MIT/Apache) — serialization
log (MIT/Apache) — logging facade
Banned Dependencies
sqlite3-sys (public domain, but C-based)
ffmpeg-sys / ffmpeg-next (LGPL/GPL)
Any crate with GPL, LGPL, AGPL, or MPL in its dependency tree
Enforcement
The deny.toml file enforces this automatically:
